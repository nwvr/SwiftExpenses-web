Expenses in other currencies

When you enter a cost in a currency other than US dollars, SwiftExpenses converts it with the US Treasury reporting rate of exchange.

  • The rate used is the latest Treasury rate published on or before the expense’s start date.
  • The converted amount appears as Cost (USD), with the rate and its date below it.
  • A line like this is added to the remark, so the report shows where the number came from:
    Currency conversion: EUR to USD using US Department of Treasury exchange rate 1.0406 (rate date: 2024-12-31)

The amount updates when you change the cost, the currency or the start date. You can type any three-letter currency code; NTD is treated as Taiwan dollars (TWD).

Keeping rates up to date

Exchange rates (US Treasury) and per-diem rates (GSA and State Department) are checked against the official sources every week and updated whenever they change. SwiftExpenses downloads the latest tables when it starts and keeps them for offline use, so you don’t need to update anything yourself. The Data Sources page of an exported report shows when the tables were last updated.
