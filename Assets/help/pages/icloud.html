Use your expenses on iPhone and Mac

Turn on iCloud sync for a library to see and change it on your iPhone, iPad and other Macs signed in to the same Apple Account. Each device keeps a full copy, so you can work offline; changes sync when you’re back online.

Turn on sync on your Mac

  1. Open the library you want to sync.
  2. Choose File > Sync This Library with iCloud.

The bottom of the sidebar shows the sync status. The first sync uploads every receipt PDF, which can take a while for a large library. Click the status to sync right away, or choose File > Sync Now.

Open the library on iPhone or iPad

  1. Open SwiftExpenses and tap Open from iCloud.
  2. Tap the library. It downloads to the device and stays in sync from then on.

To open a synced library on another Mac, choose File > Open Library from iCloud.

Good to know

  • Changes you make with the earlier Python app on the same library are picked up and synced the next time SwiftExpenses syncs.
  • If the same expense is changed on two devices at once, the change saved last is kept.
  • To stop syncing a library on a device, choose File > Sync This Library with iCloud again. The library stays on the device and in iCloud.
  • Receipts count toward your iCloud storage.
