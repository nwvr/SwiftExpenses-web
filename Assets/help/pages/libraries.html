Open or create a library

A library is a folder that holds your expenses database (expenses.db) and a reports folder. It’s the same folder layout the earlier Python Expense Report Manager used, so either app can open it.

The first start

When no library is open, SwiftExpenses shows a short guide with three choices:

  1. Start a new library. Enter a name, such as “Expenses 2026”. On the Mac the library goes to Documents/SwiftExpenses/<name> (click Choose for another place); on iPhone and iPad it goes to the app’s folder (Files › On My iPhone › SwiftExpenses). Leave Sync with iCloud on to use the library on your iPhone, iPad and other Macs.
  2. Use a library from iCloud, when you already use SwiftExpenses on another device with iCloud sync on. Pick the library; it’s downloaded to this device and stays in sync.
  3. Open an existing library: a library folder made earlier, by the Python app, or the “Review Library” folder of a submission zip.
Why not iCloud Drive? Keep the library folder in Documents (or another local folder) and let iCloud sync copy the changes. A database file in iCloud Drive itself can be damaged when two devices write to it at the same time.

Open a library

  1. Choose File > Open Library (or press ⌘O).
  2. Select the library folder itself, not the expenses.db file inside it, then click Open.

SwiftExpenses opens the same library the next time you start the app. The library’s name appears in the window’s title.

Tip: In the Open dialog, press ⇧⌘G and type a path, such as ~/Documents/SwiftExpenses, to go straight to a folder.

Create another library

  1. Choose File > New Library.
  2. Enter a name, check the location and whether it syncs with iCloud. The full path is shown before you create it.
  3. Click Create Library. SwiftExpenses creates the folder, an empty database and a reports folder.
Note: The first time you open a library made by the Python app, SwiftExpenses tidies up how trip types are spelled (for example, “CONFERENCE” and “Conference ” both become “Conference”). Nothing is deleted.
