Open or create a library

A library is a folder that holds your expenses database (expenses.db) and a reports folder. It’s the same folder layout the earlier Python Expense Report Manager used, so either app can open it.

Open a library

  1. Choose File > Open Library (or press ⌘O).
  2. Select the library folder itself, not the expenses.db file inside it, then click Open.

SwiftExpenses opens the same library the next time you start the app. The library’s name appears in the window’s title.

Tip: In the Open dialog, press ⇧⌘G and type a path, such as ~/Python/SwiftExpenses/Libraries, to go straight to a folder.

Create a library

  1. Choose File > New Library.
  2. Enter a name, such as “Work 2027”, and choose where to put it. The full path is shown before you create it.
  3. Click Create. SwiftExpenses creates the folder, an empty database and a reports folder.
Note: The first time you open a library made by the Python app, SwiftExpenses tidies up how trip types are spelled (for example, “CONFERENCE” and “Conference ” both become “Conference”). Nothing is deleted.
