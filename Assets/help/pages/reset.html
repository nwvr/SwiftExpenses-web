Remove everything from a library

Reset Library deletes every expense, every MS&IE day and the reports folder in the open library. It can’t be undone.

  1. Make sure the library you want to empty is open (its name is in the window’s title).
  2. Choose Tools > Reset Library.
  3. Click Reset Library to confirm.
Important: If you might need the data again, copy the library folder somewhere safe first.
