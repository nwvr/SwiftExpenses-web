Use SwiftExpenses in a web browser

The web version works in Chrome, Edge and Safari, on Mac and Windows. It uses the same libraries and gives the same totals as the Mac app. Everything stays on your computer: there is no account and nothing is uploaded.

Open a library

  1. Click Open Library File and choose the library’s expenses.db file, or click New Library.
  2. The library is kept in this browser, so it opens again next time. Use the menu at the top left to switch between libraries.

Save your work to a file

Click Save Library File to write the library back to an expenses.db file (a dot on the button means there are changes not yet saved to a file). Keep that file in its library folder to open it in the Mac app. Clearing the browser’s website data removes the copy kept in the browser, so save to a file regularly.

Add receipts, MS&IE and exports

These work as in the Mac app: click + New Expense and choose the receipt PDF; open a report for its receipts and MS&IE days; use Export Report (PDF + Excel) and Export Summary to Excel to download the PDF and Excel files.

How receipts are read in the browser

The receipt’s text is read in the page (scans are recognized with built-in text recognition), then your vendor templates and text rules fill in the details. In Chrome and Edge on recent computers, click Use the Browser’s AI Model once to download the browser’s own on-device model, which reads receipts much like Apple Intelligence does. In other browsers with WebGPU (for example Safari), click Download Reading Model instead: it downloads a small open model (about 1 GB, once; the browser keeps it) that runs in the page. Either way, the receipt never leaves your computer.

Note: The web version does not sync with iCloud. To move a library between the web version and the Mac app, save it to a file and open that file.
