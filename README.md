# SwiftExpenses (web)

The compiled web version of SwiftExpenses: Swift compiled to WebAssembly. Open the site,
then **Open Library File…** to pick an `expenses.db`, or **New Library…**.

Everything runs in your browser. Libraries are kept in the browser and saved with
**Save Library File**; nothing is uploaded. Receipt reading uses the browser's own AI model
(Chrome/Edge) or an optional downloadable model, also on your computer.

This repository holds only the built files; the sources are private.
